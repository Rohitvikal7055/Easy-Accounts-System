# Easy Accounts System

A simple Account Management System developed using C programming language.

## About Project

Easy Accounts System is a console-based application that helps users manage account records easily. 
This project is created for learning C programming concepts like functions, structures, file handling, and menus.

## Features

- Create new account
- View account details
- Deposit money
- Withdraw money
- Search account
- Delete account
- Simple menu-driven interface

## Technologies Used

- C Programming Language
- File Handling
- Structures
- Functions

## How to Run

1. Download or clone this repository.
2. Open the project file in a C compiler.
3. Compile the program.
4. Run the executable file.
